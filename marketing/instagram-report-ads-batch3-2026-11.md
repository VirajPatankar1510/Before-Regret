# Instagram batch 3, November 2026: Report Ads, the "Derick" format

Five businesses we have not contacted before. The owner sends each message by hand from @check_before_regret.
Claude read the profiles and websites on 2026-11-12 and sent nothing.

**Why this format (owner, 2026-11-12):** messages with links got no replies. The only reply came from the Derick
message, which has these traits:
- it opens with the person's name and one specific thing about their work;
- it has no link;
- it offers something exclusive (one per ZIP);
- it ends with an easy question.

Send the /report-ads/ link only after they reply.

Every trade below maps to a finding our report already shows (`PRIORITY_TRADE_CATEGORY` in `src/data/sponsoredVendors.ts`).
"One per ZIP" is true: `MAX_SLOTS_PER_ZIP_TRADE = 1`.
